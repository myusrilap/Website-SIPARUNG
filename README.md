# 🏢 SIPARUNG — Sistem Informasi Peminjaman Ruang

SIPARUNG (**Sistem Informasi Peminjaman Ruang**) merupakan aplikasi berbasis web yang dikembangkan untuk membantu proses pengelolaan dan peminjaman ruang secara terkomputerisasi.

Project ini dikembangkan sebagai bagian dari **kegiatan Praktik Kerja Lapangan (PKL)** dan dikerjakan secara **kolaboratif dalam tim**.

## 🎯 Features

* 🔐 Login & Registration
* 🏢 Room Booking Management
* 📅 Calendar & Schedule Management
* 📋 Data Management
* 📁 File Upload
* 🖥️ Admin Dashboard

## 🛠️ Tech Stack

## 🚀 Running the Project

### Requirements

* XAMPP
* PHP
* MySQL
* Web Browser

### Installation

1. Clone repository:

```bash
git clone https://github.com/myusrilap/Website-SIPARUNG.git
```

2. Place the project inside:

```text
xampp/htdocs/
```

3. Start **Apache** and **MySQL** using XAMPP.

4. Create the required MySQL database.

5. Configure the database connection in:

```text
koneksi.php
```

6. Open the application:

```text
http://localhost/Website-SIPARUNG/
```
